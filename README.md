 CADASTRO-DE-PRODUTOS
Neste projeto, ultilizando a linguagem Python, realizei um código em que é possível cadastrar produtos. O usuário, após escolher 1 para cadastrar, poderá iniciar o cadastro, digitando o nome, código, preço e a quantidade em estoque do produto. O usuário poderá listar os produtos (escolhendo a opção 2) e excluir produtos (escolhendo a opção 3), ou, se desejar sair do progama, apertando a opção 4.
